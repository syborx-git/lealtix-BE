📋 NUEVO ENDPOINT CREADO:
═══════════════════════════════════════════════════════════════════════════════

MÉTODO:          GET
RUTA:            /api/dashboard/waiter/summary/by-date-range
BASE URL:        http://localhost:8080
SEGURIDAD:       @PreAuthorize("hasAuthority('dashboard_mesero')")
PARÁMETROS REQUERIDOS:
  • tenantId (Long): ID del tenant/empresa
  • userId (String): ID del usuario autenticado
PARÁMETROS OPCIONALES:
  • from (LocalDateTime): Fecha inicio en formato yyyy-MM-dd'T'HH:mm:ss
  • to (LocalDateTime): Fecha fin en formato yyyy-MM-dd'T'HH:mm:ss

COMPORTAMIENTO:
  • Si from y to se proporcionan: busca en ese rango
  • Si from y to son null: retorna datos de HOY (mismo que /summary)
  • Si solo uno de los dos se proporciona: se ignoran las fechas y busca hoy

import requests
from datetime import datetime, timedelta

token = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...'

# Últimos 7 días
to_date = datetime.now()
from_date = to_date - timedelta(days=7)

from_str = from_date.strftime('%Y-%m-%dT%H:%M:%S')
to_str = to_date.strftime('%Y-%m-%dT%H:%M:%S')

headers = {
    'Authorization': f'Bearer {token}',
    'Content-Type': 'application/json'
}

params = {
    'tenantId': 36,
    'userId': 'waiter_001',
    'from': from_str,
    'to': to_str
}

response = requests.get(
    'http://localhost:8080/api/dashboard/waiter/summary/by-date-range',
    headers=headers,
    params=params
)

if response.status_code == 200:
    data = response.json()
    print('Dashboard (7 días):', data)
else:
    print(f'Error: {response.status_code}')

import org.springframework.web.client.RestTemplate;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpEntity;
import org.springframework.http.ResponseEntity;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

RestTemplate restTemplate = new RestTemplate();
String token = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...";

HttpHeaders headers = new HttpHeaders();
headers.set("Authorization", "Bearer " + token);
headers.set("Content-Type", "application/json");

LocalDateTime from = LocalDateTime.of(2026, 3, 23, 0, 0, 0);
LocalDateTime to = LocalDateTime.of(2026, 3, 30, 23, 59, 59);
DateTimeFormatter formatter = DateTimeFormatter.ISO_DATE_TIME;

String url = String.format(
    "http://localhost:8080/api/dashboard/waiter/summary/by-date-range?" +
    "tenantId=36&userId=waiter_001&from=%s&to=%s",
    from.format(formatter),
    to.format(formatter)
);

HttpEntity<String> entity = new HttpEntity<>(headers);

ResponseEntity<WaiterDashboardSummaryDTO> response = restTemplate.exchange(
    url,
    HttpMethod.GET,
    entity,
    WaiterDashboardSummaryDTO.class
);

WaiterDashboardSummaryDTO summary = response.getBody();
System.out.println("Dashboard (7 días): " + summary);
